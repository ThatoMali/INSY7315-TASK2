Workflow

How it works

Every incident follows the same auditable path from the field to resolution.

  1. 1

    Report

    Field rangers log an incident with GPS, a photo and notes — online or offline.

  2. 2

    Assess

    The server assigns a severity (High / Medium / Low) using rule-based triage.

  3. 3

    Notify

    High-severity incidents auto-escalate and raise an in-app alert for the section.

  4. 4

    Track

    Section rangers and admins manage status with a full audit trail.

  5. 5

    Record

    Fines and proof of payment can be attached to an incident. (Test mode)

Capabilities

Core features

Incident reporting & tracking

Structured, GPS-tagged incident capture with photo evidence and searchable history.

AI-assisted severity

Rule-based scoring across incident type and notes. Not a trained model.

Emergency / SOS

One-tap urgent report for field rangers that logs a High-severity incident and raises an alert.

Assignment & status

Section rangers and admins manage incidents end-to-end with role-based access.

In-app notifications

High-severity alerts appear on the section dashboard. In-app only.

Fines & payments

Record fines against incidents. Simulated test mode.

Admin & audit

User accounts, roles, deactivation and an immutable audit log of key actions.

Dashboard analytics

Live counts, an incident map and a breakdown by type for the signed-in section.

Who it's for

Intended users

Field Rangers

Report incidents from the field — GPS, photo, offline queue.

Section Rangers

Monitor, escalate and resolve incidents within their section.

Regional Ecologists

Read-only access across sections for cross-sectional analytics.

System Administrators

Manage users, roles, accounts and the audit log.
